## Answer first

**Tag after two small tasks and the text. Nothing else blocks.** Opus's verdict is the right one: no finding breaks a
v0.44.1 project that is configured the default way. agy's "fix four before tagging" comes down to two real fail-open
paths, both reproduced here, both a few lines:

1. **OpenCode: a shell call with a working directory and no readable command is allowed** (agy B1; Q1, Q2). The
   plugin sends `cd '<dir>' && ` for it (`opencode/obor.js:168-170`), which is not empty, so the guard's
   empty-command deny does not fire, and the guard allows a command its parser rejects (`internal/guard/shell.go:80-85`).
   This is the case the guard's rule exists for ("a renamed CLI argument arrives as an empty one",
   `internal/guard/guard.go:24`), and agy's transport already has the check (`kinds/agy/kind/hook.go:215`). Three lines.
   agy B3 (a `patch` with no text goes as `unguarded`, not as the empty-file write) is one line in the same function.
2. **The shim's agy hook with no usable binary answers nothing to a tool call it cannot name** (Opus F3, agy B2.1 and
   B2.2; Q3). agy runs a tool whose hook prints nothing (P14). Three cases reach that: a nested `"hookEventName"` key
   in an MCP call's arguments, a cut-off event, and an event whose key is spelled another way. Three lines close all
   of them (Q4).

Neither is likely (the first needs OpenCode to rename an argument, the second a machine with no obor binary). Both are
in claims this wave made (T-1526's shared transport row, T-1523 and T-1530), both fixes are known and small, so they go
before the tag. Everything else is next wave, accepted, or dropped.

The decisions, short (details in §3 and §5):

- **agy's model list (Opus F2, agy B4):** one fix, next wave, and each reviewer's half alone makes the other's worse.
  Not before the tag: it refuses a start loudly, it does not fail open, and its task needs agy's live tier.
- **Codex lanes and `mcp_servers` args (Opus F1, agy B7):** the refusal at dispatch names the fix. The upgrade guide
  carries a one-line check; `obor config validate` learns it next wave, through the kind, not by naming Codex.
- **The transition cleanup** (the release after this one) takes the design items with it: agy's hook calls
  `obor hook` in process, its project detection uses `internal/project`, and the live conformance tier runs the linked
  kinds (today it runs the built binaries, agy D3).
- **agy 1.5.15:** nothing found. `agy models` has the same format, and agy b, itself a session of 1.5.15, listed its
  17 tools and found each in the transport's table.

## Risks

- A2's rule reads "a tool call" from the raw text `"toolCall"`. An agy that renamed that key would be answered by

- W1's strict parse refuses a format agy might move to (a list with no tab). That start then runs on the cached

## Concerns

- **A transport that builds text around an argument can defeat the guard's empty-argument deny, and the guard
  allows what its parser rejects** (`internal/guard/shell.go:47` documents it). B1 is one instance; `git worktree add
  ''` for a worktree tool with no argument is another shape of it that happens to be denied. Recommendation: the
  shared conformance row (GT-S*) sends each transport its renamed-argument case with every optional argument set
  too, so the next composed command is caught by the row, not by a deep dive. Related and outside this range: Q2
  showed `echo ${(U)foo}; git commit -m x` exits 0 for an advisor, because the first statement is zsh syntax the
  bash parser rejects. That matters wherever an agent's shell is zsh; it is the documented limit, and worth one
  owner decision on whether an unparsed command should be denied for roles that have git denies.
- **Two releases in a row carried an item that the previous advice had tied to a later task and nobody picked up**
  (the kind's process groups "with the link-in"; before that, design.md after the docs sweep). Recommendation: an
  accept row whose fix is "with task X" goes into X's BACKLOG line when the advice is read, so the spec's author
  sees it.
