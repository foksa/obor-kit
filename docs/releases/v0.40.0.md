A lead you start now asks before it acts, bare `obor review` only shows, the merge gate never merges a moved candidate untested, and obor web's Docs page is redesigned.

- **Lead start:** `obor lead` and `/obor:lead` inspect and present the state and options, then wait; only the lead's handoff restart continues on its own.
- **Review command:** bare `obor review` shows the review state; `obor review start` starts one.
- **Merge gate:** with no `merge.compile`, a candidate whose target moved re-runs `merge.check`; init no longer sets compile (it suggests a typecheck script), composes `merge.check` from lint, typecheck, check and test, and warns on a check that writes files.
- **Lanes:** obor's own linked files never make a lane dirty at dispatch, test or drop; a waiting dispatch names the dirty lanes and paths.
- **Docs page:** filter and full-text search, pinned cards, recent docs and a folder tree, an outline that follows the scroll, section links, titles, doc-kind colors, and narrow-screen drawer and sheet.
- **Fixes:** light-theme tone colors reach 4.5:1 contrast; review close ignores unrelated untracked files; `NOT IDLE` says why; a permission-dialog needs-you keeps the command; bold around inline code renders; Go 1.27.4.

Upgrading: a script that started reviews with bare `obor review` must use `obor review start`; set `merge.compile` (e.g. a typecheck) for fast moved re-gates. See `docs/UPGRADE-v0.40.md`.
