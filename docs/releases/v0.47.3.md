Each Claude session obor starts is named after its project and agent, so leads are told apart in the session list.

- **Session names:** every Claude agent obor starts or resumes gets `--name "<project> <agent>"` (e.g. `obor-kit ob-lead`), shown in the prompt box, the `/resume` picker, the terminal title and the phone's Remote Control list. A `--name` or `-n` in the agent's args wins. Other kinds take no name at start and are unchanged.

Upgrading: restart the lead once (`obor lead --resume`) to pick up its name; other agents get theirs at their next start (`docs/UPGRADE-v0.47.md`).
