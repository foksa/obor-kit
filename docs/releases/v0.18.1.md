A patch release: built with Go 1.27.3, and releases now carry notes.

- **Go 1.27.3:** obor is built with Go 1.27.3, which fixes five HTTP server issues in Go 1.27.1 that `govulncheck` reports for `obor web`. `obor web` serves plain HTTP on localhost, so there was no real exposure.
- **Release notes:** every GitHub release gets a title and notes like these, with a Full Changelog link to the previous release.

Upgrading: re-run the installer, then `obor serve restart` in each project.
