Agents start without the owner's own plugins and skills, overridable per project in each CLI's own format, and the code for old versions goes.

- **Trimmed agent starts:** every agent but the lead starts with the user's plugins and skills off (Claude, Codex, OpenCode); env, hooks and the rest of the user's settings still apply.
- **Override files:** `.obor/claude/settings_override.json`, `claude_override.json`, `.obor/codex/config_override.toml`, `hooks_override.json` and `.obor/opencode/opencode_override.json`, merged over the user's own files (JSON Merge Patch: `null` deletes), keep a plugin or remove a hook or MCP server for a project's agents.
- **Role worktrees get `lanes.links`:** an uncommitted `.claude/settings.json` reaches the integrator, reviewer and deep dive too.
- **Session ids from obor's own record:** start decisions no longer depend on herdr's session report.
- **Version watch:** serve tells the lead when an agent CLI or herdr changed version; `obor status` names agents running on another obor release.
- **Safer web:** `obor web` answers only to loopback Host names.
- **Nightly:** one race-detector run (non-gating), a red's failing tests rerun once.
- **Old-version code removed:** shape-1 config detection, the old herdr plugin removal, the pre-v0.23 upgrade guides and tests, and other compatibility reads.
- **Platforms:** obor no longer claims Linux support until something tests it.

Upgrading: nothing to do; see `docs/UPGRADE-v0.35.md` for what agents now see.
