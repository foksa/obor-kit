Internal restructuring after an architecture review; no workflow change.

- **One start flow:** every agent start (setup, lead, drive, serve's starts and restores) goes through the same code; one placement rule for herdr and hc.
- **Config in serve:** each config carries its own plugin kinds; serve reads one config per pass. On hc a plugin kind added to the config starts without a serve restart.
- **obor setup --start** takes a pane you name whatever its directory; a quarantined Codex install refuses worker and role starts with the fix line.
- **obor drive** refuses while serve is still on another obor build, instead of recording a drive it cannot report.
- **Retry hints** after a failed fresh start say `--fresh`.
- **Nightly:** the budget line warns per package when tests grow faster than code.
- **Tests (contributors):** a full test run starts half the git processes it did (5,351 → 2,671); the core's tests run on a terminal-neutral fake, so a scenario holds for herdr and hc alike.
