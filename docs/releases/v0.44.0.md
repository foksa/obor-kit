Agents other than Claude Code can lead: OpenCode and agy leads get their lines like a Claude lead, and agy (Antigravity CLI) is a new kit kind.

- **agy:** add a model of kind `agy` (e.g. `"gemini": {"kind": "agy", "id": "gemini-4-neon"}`) and run `obor setup agents`; commit the `.agents/` files it writes. Agents start in auto mode with obor's commands allowed; obor's hooks guard them. Project settings go in `.obor/agy/settings_override.json`.
- **Leads of any kind:** a kind without a slash command starts its lead on the skill file; `obor whoami` shows how lines reach the lead (`inbox`, `hooks` or `status`); a lead without an inbox gets its lines through its hooks.
- **OpenCode:** agents resume their session, report context size (handoff reminder), act on obor's hook answers, and have an inbox: wakes, briefs and lead lines are posted, and an idle OpenCode lead is woken.
- **Restarts:** the session a restart resumes or adopts is recorded with its kind.
- **Reviews:** a fix task dispatched before its review started still triggers the verify.
- **Plugin kinds (authors):** the protocol gains context reads, long headless flags, `caps.app`, `caps.hook_answers`, an inbox, project-file installs and a hook transport contract.
- **Tests (contributors):** `internal/launch` and `internal/setup` run faster.

Upgrading: nothing to run; OpenCode agents pick up the new plugin at their next start. See `docs/UPGRADE-v0.44.md`.
