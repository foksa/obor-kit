A lead you start now always asks you first, and the web monitor shows when the lead is working.

- **Lead start:** `obor lead` no longer starts the lead in handoff mode when its model names an effort; the lead's own handoff restart is now `obor restart <lead> --handoff`, and a plain `--fresh` restart asks you first.
- **Restart outside a project:** `obor restart` without a project config prints one line instead of crashing.
- **Web nav:** a project shows as working while its lead or a role agent works, not only while a lane is busy.

Upgrading: nothing to do. See `docs/UPGRADE-v0.40.md`.
