A lead you start now always asks you first, a RED nightly's needs-you follows the last check, and the web monitor shows when the lead is working.

- **Lead start:** `obor lead` no longer starts the lead in handoff mode when its model names an effort; the lead's own handoff restart is now `obor restart <lead> --handoff`, and a plain `--fresh` restart asks you first.
- **Nightly:** a hand `obor nightly` settles a RED nightly's needs-you like the scheduled run (GREEN ends it, RED at another commit replaces it); `obor resume nightly "<why>"` acknowledges a RED one and stops its hourly repeat until the next RED run.
- **Restart outside a project:** `obor restart` without a project config prints one line instead of crashing.
- **Web nav:** a project shows as working while its lead or a role agent works, not only while a lane is busy.

Upgrading: nothing to do. v0.40.2 was not published; this release carries it. See `docs/UPGRADE-v0.40.md`.
