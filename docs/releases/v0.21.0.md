- **Setup edits from obor web:** the Setup page edits a difficulty level's types (reorder, add, remove), a lane type's model, effort and max, a lane's type, a role's type, and sets or clears the pause. Serve validates each change, writes `.obor/config.json` and commits it on main (`config: <key> <old> → <new> (owner, web)`), and the lead gets the same line; a config with uncommitted changes or a lane with a task is refused. Edits are taken only from the page's own origin on localhost.
