Reviewers and deep dives probe in one directory per agent that serve empties when it stops them, and a path the worktree tracks is never replaced by obor's link.

- **Probe dir:** every review, verify and deep dive brief names one probe directory per project and agent, outside the checkout; serve empties it when it stops the agent (the reviewer after its review closes, `obor restart --stop`). Probe copies and per-review Go or cargo caches no longer pile up in the temp dir. A sandbox that cannot write the shared Go cache (Codex) puts it there.
- **Links:** a `lanes.links` entry whose path the worktree's HEAD tracks is never linked, so a worker's deletion of a tracked file stays a deletion (non-ASCII names included).
- **Replies:** a call whose record is in the log (`obor send`, `pause`, `land`) never replies "the event log refused it" when only the lane-row write failed; a retry no longer sends twice.
- **agy:** the `update_steps` checklist tool (agy 1.5.17) is allowed.
