Claude workers load only obor's MCP server, and serve restarts survive a slow launchd.

- **Strict MCP for workers**: every Claude lane worker and drive starts with `--strict-mcp-config` and obor's
  `--mcp-config`, so it no longer loads every MCP server of the user's (context on every job). The lead and role
  agents are unchanged.
- **`obor serve restart` / `install`**: a kickstart that outlives the old deadline, or errors after the restart
  happened, reports RESTARTED from the new pid; an install that hits launchd's bootstrap I/O error boots the label out
  and bootstraps once more, and says what state it left otherwise.

Upgrading from v0.23.0: nothing required.
