Fewer waits and hand steps: merges go on during reviews, serve runs a review's fix round, and stopping an agent no longer blocks the command.

- **Role worktrees:** the reviewer, deep dive and integrator each work in a worktree serve owns, so merges no longer
  wait while a review runs (the merge hold is gone).
- **Review fix rounds in serve:** `obor review fix T-a,T-b` links fixes to the open review; serve verifies them in the
  same reviewer session once merged, and close waits for that verify.
- **Verbs answer first:** moving, dropping or taking over a task replies at once; the agent's stop is a step serve
  replays after a restart, and a task with a stop pending is busy for other verbs.
- **Help page:** `obor help` and obor web's Help page list every command by group, plus how to install and set up a
  project.
- **Idle line:** sent only once the pipeline has stayed idle for a minute, so a verify or review that is about to
  start no longer triggers a false ping.

Upgrading: re-run the installer, then restart every serve.
