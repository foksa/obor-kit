`obor init` in an empty folder sets everything up and starts the lead.

- **One command:** `cd` into an empty folder, run `obor init` in herdr or in a herdr-app (hc) terminal. It picks the terminal you typed it in (`--terminal` overrides), makes one commit, and starts the lead in the same pane when that pane is alone in its tab.
- **Fewer questions:** init asks nothing; the lead asks once whether to keep the models and lanes.
- **`obor lead`** in a folder with no config runs `obor init`.
- **herdr's agent resume:** `resume_agents_on_restore = false` is now optional; after a herdr restart serve replaces the agents herdr resumed on its own with obor's start, and stops the ones with no open work.
- **OpenCode:** the kind passes its own launch flags; validate messages name the right kind.
