Projects can add their own roles, the lead hears when the swarm goes idle, and opencode gets obor per launch.

- **Custom roles:** one `roles.<name>` config row plus `docs/agents/<name>.md`; advisor, researcher and triage are
  such rows now, and the advisor may write `docs/research/` and `docs/plan/`.
- **Idle ping:** serve tells the lead when nothing is in flight; `obor idle "<why>"` acknowledges.
- **Spec changes reach a worker at task_done:** `obor spec set --note "<what changed>"` records the note with the new
  rev, and `task_done` refuses work done against an older spec rev once with the rev and the note.
- **opencode per launch:** obor's MCP server and plugin come from the launching kit; run `obor setup agents` once all
  projects run v0.25.1 to remove the old global registration.
- **Safer agent starts:** one list of obor's env vars, unset on every start; Claude session ids chosen by obor; Codex
  starts with `--no-daemon`, efforts up to `ultra` (`minimal` refused).
- **herdr protocol 22 and newer** accepted; `make conformance` checks the installed agent CLIs and herdr.
- **Nightly commands:** `merge.nightly_commands` runs extra non-gating commands each night.
- **Merge subjects** from the spec title; the body keeps the worker's whole summary.

Upgrading: see `docs/UPGRADE-v0.25.md` (v0.25.1: restart every serve, then `obor setup agents` once per machine).
