Fixes from running a project on herdr-core end to end.

- **obor init:** a config you wrote yourself gets its missing agent prefix; no agent starts with an empty name.
- **Committed link files:** committing a file obor linked into the worktrees (such as `.claude/settings.json`) no longer stops dispatches, and every worktree keeps the plugin settings across checkouts.
- **Restore:** on herdr-core a lost holder restores every pane it held, the lead included; a restored worker picks up its open job by itself.
- **obor resume:** takes a line to an idle worker of a working task.
- **Web page:** shows agents waiting for your input.
- **Reviews:** `obor review start` works without `reviews.dir` set.
- **herdr-core notifications:** shown as macOS notifications.

Upgrading: nothing to do. See `docs/UPGRADE-v0.41.md`.
