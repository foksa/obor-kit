Put a project to sleep with `obor stop`, no more idle agents after setup, and opencode model selection through obor's plugin.

- **`obor stop` / `obor start`:** stop a project's agents and serve, drop it from the project list and stand its hooks down; `obor start` wakes it. Work in progress is refused unless you pass `--force`.
- **No idle agents:** `obor init` and `obor setup` label panes without starting agents; every agent starts when it is first needed.
- **Smoother `obor init`:** the obor plugin reaches every lane even when `.claude/settings.json` is not committed, and `obor status` flags a Claude lane without it.
- **opencode model and effort:** obor's opencode plugin sets the model and effort obor asked for on each new session, replacing v0.19.0's per-agent state directories.
- **Researcher role:** a role pane for research that writes only `docs/research/`; role write limits now also cover shell commands and git.
- **Web and monitor:** a project whose config is newer than the binary still shows, with a warning.

Upgrading: re-run the installer, then `obor serve restart` in each project. Details in `docs/UPGRADE-v0.19.md`.
