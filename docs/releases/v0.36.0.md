Role worktrees get the same setup as lanes, a blocked worker reaches the lead at once, and an unwritten review can be closed.

- **Role worktree setup:** the reviewer's and deep dive's worktrees run `lanes.ready` / `lanes.setup` whenever serve moves them, so their tests find installed dependencies.
- **Blocked workers:** a worker waiting on a question or a dialog is a needs-you as soon as serve sees it, with the question read from its pane, in the lead's line, the owner's notice, `obor status` and the web.
- **Unwritten reviews:** `obor review close --force` closes a review whose reviewer stopped before writing it, when it covers no task; one that covers tasks names how to have it written.
- **Old record replay:** branches for record shapes no live log holds are gone; lead lines recorded before they carried their key still count as sent.
- **Release and tests:** the release's rerun reads failed packages only from `go test`'s own FAIL lines; the app's test rig ends a stalled wait in wall time.
