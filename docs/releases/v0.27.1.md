Two small fixes to v0.27.0.

- **Idle line after an ack:** an idle state acknowledged with `obor idle` during its one-minute settle window no longer
  gets its line afterwards.
- **`obor serve restart` waits for serve:** restart and install return once the new serve answers on its socket
  (`serve ready`), or fail after a bounded wait, so a command right after a restart no longer finds no serve.

Upgrading (v0.27.1): re-run the installer, then restart every serve.
