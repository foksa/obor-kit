Serve opens a lane's missing pane by itself, and a start held by a "Trust this folder?" dialog counts as started instead of failing. Small fixes for leads of new projects come with them.

- **Lane panes:** a worker start in a lane with no pane opens one in a lane tab instead of stopping at "no pane in lane".
- **Trust dialogs:** a fresh review, dispatch or brief held by the agent's trust dialog is recorded as started; a needs-you names the pane and clears once you answer it (for Claude, pick "Yes": the default is "No, exit").
- **`obor idle`:** works on a project with no merge yet.
- **`obor spec set`:** lists the models dispatch would try for the spec.
- **`obor config validate`:** says when a config change counts (serve's next pass, or the keys that need a serve restart); the "merge.compile is empty" warning appears at `obor init` only.
- **Releases:** a version that was tagged but never shipped is no longer taken as the previous release.

Upgrading: nothing to do. See `docs/UPGRADE-v0.40.md`.
