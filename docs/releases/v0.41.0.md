herdr-core as an experimental terminal, `obor prune` and `obor uninstall`, and the web page as its own launchd agent.

- **herdr-core (experimental):** `"project": {"terminal": "hc"}` runs a project's agents in herdr-core (`hc` 0.1.21+), shown in herdr-app as a project space with `lead`, `lanes` and `roles` tabs; herdr stays the default.
- **Restore only what was lost:** after a terminal reconnect, serve restarts only the panes whose process was lost; on herdr nothing changes.
- **obor prune:** deletes the branches of merged tasks and the worktrees of lanes and roles the config no longer names, printing each tip sha; the nightly prunes branches merged more than 7 days ago.
- **obor uninstall:** undoes `obor init` in a project, keeping the config and committed files (`--purge` also removes `.obor/state`).
- **obor lead in a new project:** runs `obor init` first when the repository has no obor config.
- **obor web:** the page runs as its own launchd agent, `obor.web`, kept alive next to each project's serve.
- **Workers:** a `merge_preview` tool shows whether the work merges cleanly onto the target's current head.
- **Done role agents:** a role agent done for an hour with no open work gets one reminder line to the lead with its stop command.
- **Store:** only schema 14 stores open; a store last opened by v0.31 or older needs one open with v0.40.7 first.
