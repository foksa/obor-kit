agy lanes run without asking before each command, and fixes from foksa-dev's first agy week.

- **agy:** a lane worker's or drive agent's start sets `toolPermission: "always-proceed"` (obor's hooks still guard every tool); a project's override can name another value.
- **Serve:** follows a new obor binary while tasks wait in needs-you (their work no longer holds the restart), at the latest 30 minutes after it sees the binary; logs the binary it follows (path, version) and, while the restart waits, what holds it; `obor status` names the same beside "restarting serve". A worker that fetches its job again ends the needs-you a failed delivery to it left and retires a resume line not yet delivered.
- **Workers:** the wake line says obor's `job_next` tool is connected and comes first.
- **Config:** a config from an older obor fails with what to do (move `.obor` aside, `obor lead`), naming the old keys, instead of a JSON decode error.
