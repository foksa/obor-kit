obor web is redesigned, and a drive can talk to its lead and commit on its own branch.

- **obor web redesign**: a Svelte 5 + TypeScript app (source in `web/`, built by `make web` into the binary): Fleet,
  Project (lanes, pipeline, watches, roles, events), Task, Agent, Job and Setup pages. Setup edits are collected and
  committed together: `POST /api/config` takes a list of changes with the config version the page started from,
  validated together, all or nothing, one commit; an edit from a stale page or another tab is refused. The top-bar
  live mark shows the visible page's refresh failure. The binary grows by about 155 KB. Building the page needs Node
  (`make web`); `go build`, `make check` and releases do not.
- **A drive talks to its lead**: the drive agent runs `obor tell-lead "<text>"` while it drives; the lead answers with
  `obor answer T-xx "<text>"`, typed into the drive's pane when it is idle.
- **A drive commits on its branch**: the pre-commit hook lets the driver role commit in its own lane; workers and other
  roles stay refused.

Upgrading from v0.21: nothing required.
