Rex can be a project's terminal (experimental), and an agent's own status reaches obor's status line, needs-you and web card on hc and Rex.

- **Rex (experimental):** `project.terminal: "rex"`; `obor init` in a Rex block picks it. Put `/Applications/Rex.app/Contents/Helpers/Rex Server.rex/Contents/MacOS/rex` on your `PATH` first. Projects are laid out as on herdr without taking focus; agents start with a clean environment; workers may only read with `rex`.
- **Agent status (hc, Rex):** each agent's OSC 7501 report is the status, read in one place for every terminal; a blocked agent's kind and message (`permission: approve Bash: …`) or an error's message show on its `obor status` line, its needs-you and the web card.
- **Prompts:** one check on every terminal refuses to type into a blocked agent before any key is sent.
- **hc:** a core started from another terminal's or obor's pane is refused with the restart line; serve starts a core with every other terminal's identity removed.
- **agy:** reports itself as `antigravity`; the live tiers run agy on hc and Rex.
