A terminal restart no longer brings back role agents that were stopped, and dispatches no longer stop on a stale lane lock.

- **Restore:** after a terminal restart, serve restarts only the lead, workers on busy lanes and role agents with open work (a brief, the integrator's job, a review); a role agent stopped on purpose stays stopped and its next brief starts fresh.
- **Lane locks:** obor's git reads take no `index.lock`, and a dispatch's lane checkout removes a stale lock once (logged) instead of stopping at needs-you.
